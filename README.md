# 天朝小将 · 纯本地版

《天朝小将 2.8》网页游戏的**完全本地化版本**，无需任何服务器，双击即可游玩。

## 快速开始

**方式一（推荐）：双击 `play.bat`**
自动启动本地服务器并打开浏览器。

**方式二：手动**
```bash
python -m http.server 8090 --directory .
```
浏览器打开 `http://127.0.0.1:8090/game.html`

**方式三：直接打开**
双击 `game.html`（使用 `file://` 协议，功能完整）。

## 本地化改造说明

### 已实现
| 功能 | 说明 |
|---|---|
| 登录/注册 | **已移除**，无需账号密码，自动分配本地账号 |
| 云存档 | **已移除**，数据直接保存在浏览器 `localStorage` |
| 战斗 | 本地模拟，复用游戏内置战斗引擎生成战斗回放 |
| 存档 | 自动保存到本机浏览器，刷新/重开自动恢复 |
| 重置账号 | 清空全部本地数据（存档/排行榜/账号），重新开始 |
| 静态资源 | 音频、图片、怪物头像全部下载到本地 `audio/`、`images/` |

### 降级内容（无真实玩家）
- 聊天、好友、公会、邮件：返回空数据（无其他玩家）
- 排行榜、斗神殿：只有本地自己
- 云宝、帮派战：本地模拟

## 目录结构
```
tianchaoxiaojiang/
├── game.html             # 游戏本体（已本地化）
├── local-adapter.js      # 本地适配层（拦截网络请求，本地模拟）
├── audio/                # 音效与背景音乐（21个）
├── images/               # 图片资源（含 89 个怪物头像）
├── play.bat              # 一键启动
└── index.html.orig.bak   # 原始未改动版本备份
```

## 技术说明
- 适配层 `local-adapter.js` 重写 `window.fetch`，拦截所有指向 `103.236.98.227` 的请求
- 登录/注册/云存档/心跳 → 本地 `localStorage` 模拟
- 战斗 `/battle/*` → 调用客户端已有引擎本地模拟，生成 `combatRounds`
- 静态资源 URL 已在 HTML 中改写为相对路径
